# 安全说明

## 报告漏洞

请优先使用 GitHub 仓库的 **Security → Report a vulnerability** 私密报告功能。
如果该入口暂不可用，请创建不含密码、令牌、私有拓扑或运行配置的普通 Issue，
说明需要私下提供复现细节。

报告应包含受影响版本、触发条件、影响范围和最小复现步骤。请给维护者合理的
修复时间后再公开具体利用细节。

## 使用边界

- 设备 console 通信基于 Telnet，内容不加密。只应在隔离、可信的实验网络中使用。
- 不要把 eNSP console 端口暴露到公网或不可信局域网。
- 只连接并配置你有权操作的实验设备。
- 通过参数或环境变量提供设备凭据，不要把真实密码、配置或日志提交到仓库。
- 批量配置不是事务操作。命令出错时不会自动回滚已经生效的配置。
- `environment_check` 和 `ensp-mcp-doctor` 保持只读，但不能替代真实设备启动与安全评估。

本仓库不分发 eNSP、VirtualBox、固件或设备镜像；这些组件应从合法来源取得，
其安全更新和许可由各自供应方负责。
